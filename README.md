# STM32-Diode-Buck

基于 STM32F103C8T6 的简易 **非同步整流 Buck 降压电路** 设计项目。

> 本项目为大一新生入门考核项目，作为后续电子设计竞赛（电赛）的技术过渡与能力储备。

---

## 项目简介

本项目使用 **STM32F103C8T6** 作为主控，设计并制作一款简易的 Buck（降压）直流变换电路。主电路采用 **非同步整流（二极管续流）** 方案，通过 MCU 输出 PWM 驱动 MOS 管，实现降压输出，并以此掌握开关电源的基本原理、驱动电路设计及软硬件调试流程。

## 系统架构

- **主控**：STM32F103C8T6
- **拓扑**：非同步整流 Buck（二极管续流）
- **控制方式**：MCU PWM 驱动单管

## 技术选型与决策依据

| 对比项 | 非同步整流（本项目） | 同步整流 |
| --- | --- | --- |
| **效率** | 较低 | 较高 |
| **电路复杂度** | 低 | 高（双 MOS、半桥驱动、死区控制） |
| **器件成本** | 低 | 高 |
| **调试难度** | 低（单通道示波器即可观测关键波形） | 高 |

**结论**：本项目定位为入门考核，**优先保证成功率与调试便利性**，故采用非同步整流方案。
