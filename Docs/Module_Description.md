# Buck 电路系统说明

本 Buck 电路系统共划分为 9 个功能模块，分别为电源模块、LED 灯模块、按键模块、OLED 显示模块、ADC 采样模块、栅极驱动模块、Buck 功率模块和主控模块。其中 Buck 功率模块为本系统的核心功率变换单元，其余模块围绕其展开，分别承担供电、控制、交互与调试功能。


## 一、电源模块

电源模块采用 TPS54202DDCR 同步降压转换器，实现 12V 转 3.3V / 2A 的 DC-DC 变换，为 STM32 主控、OLED 显示屏及栅极驱动芯片等提供稳定可靠的 3.3V 供电。


## 二、LED 灯模块

LED 模块包含 5 个独立 LED，用于 GPIO 的基础操作考核，可分别实现流水灯和呼吸灯两种效果。流水灯通过依次点亮、熄灭各 LED 来考察 IO 口顺序控制能力，呼吸灯则通过软件 PWM 模拟呼吸效果，考察定时器与 PWM 输出能力。


## 三、按键模块

按键模块包含 4 个独立按键，主要用于 OLED 显示界面的菜单切换与参数调节、控制模式的切换（如开环与闭环切换、目标电压设定等），以及后续扩展功能的交互入口。


## 四、OLED 显示模块

OLED 模块采用 0.96 寸 I2C 接口显示屏，型号为 HS96L03W2C03，用于实时显示系统运行状态，包括当前输出电压、设定目标电压、PWM 占空比以及运行模式（开环或闭环）。


## 五、ADC 采样模块

ADC 采样模块通过电阻分压网络（10kΩ 上拉电阻与 15kΩ 下拉电阻）将 Buck 电路输出的 5V 电压衰减至 STM32 ADC 可承受的 0 至 3.0V 范围内，送入 PA1 引脚进行实时采样，所得数据用于闭环控制中的电压反馈。


## 六、栅极驱动模块

栅极驱动模块选用 TC4420 单通道高速 MOSFET 驱动器，用于将 STM32 输出的 3.3V PWM 信号转换为 12V 栅极驱动信号，驱动 Buck 功率管 NCEP0135A，确保 MOS 管快速、可靠地开通与关断。


## 七、Buck 功率模块

Buck 功率模块采用异步非同步整流拓扑，以 NCEP0135A 作为主功率开关管，SS34 肖特基二极管作为续流二极管，搭配 100μH 功率电感及输入输出滤波电容，构成完整的降压功率级，实现 12V 至 5V / 1A 的功率变换。


## 八、主控模块

主控模块采用 STM32F103C8T6 作为核心控制器，负责输出 100kHz PWM 信号驱动 Buck 功率级，通过 ADC 采样实时读取输出电压，运行 PID 闭环控制算法实现稳压输出，同时响应按键输入、更新 OLED 显示，并通过 LED 指示系统运行状态。


各模块相互配合，共同构成一套完整的 Buck 降压电源系统，既满足功率变换的功能需求，也兼顾了实验室教学考核的交互性与可观测性。
